# v0.2.0-alpha.1

## 한국어

Kubernetes 검사 엔진을 확장한 알파 버전입니다. Go/Helm/kubectl 없이 Linux, macOS, Windows 10+에서 실행할 수 있습니다. Windows x86/amd64와 두 명령 `kubewiser`, `kubewise` 지원을 유지합니다. Windows ZIP에는 EXE 하나와 두 명령 등록용 설치 스크립트가 포함됩니다.

- 공식 Kubernetes 1.16~1.37 `.0` OpenAPI 스키마 22개 내장, 출처/해시 공개, CRD 로컬 검증, unknown field/type/required 검사.
- deprecated/removed API 규칙, 조건부 권고, List 재귀 처리, 입력 제한과 위치/근거/미검사 결과.
- 명시한 클러스터·namespace의 GET 전용 스냅샷 수집. 속도·페이지·시간·개수 제한, RBAC 누락 기록, Secret 제외와 지정 필드 제거.
- 로컬 Helm 렌더링 및 snapshot drift 비교. 외부 의존 다운로드나 apply 없음.
- 버전별 업그레이드 단계·조치, kubelet skew 확인, 기존 Hubble 기록과 NetworkPolicy 격리 의도 분석, EKS/AKS/GKE 이전 의존 계획.
- 같은 엔진의 MCP 도구 확장. 모델이 파일 경로나 클러스터 범위를 바꿀 수 없으며 수집 도구는 명시적으로 활성화할 때만 제공.

**변경 사항:** 보고서 형식 v2, JSON 기본 출력, 소스 빌드 최소 Go 1.26. 실행 파일에는 Go 설치 불필요. 분석은 오프라인이며 텔레메트리가 없습니다. 명시적 수집은 선택한 API 서버와 통신합니다. MCP 클라이언트의 데이터 처리는 별도입니다.

**범위:** 마이너 `.0` 스키마 기준으로 패치별 의미 차이, admission/CEL, 실제 앱·커널 호환성, 완전한 네트워크 허용 경로, 자동 인프라 생성/데이터 이전은 검증하지 않습니다. Helm values.schema.json과 live lookup은 사용하지 않습니다. 인증 exec 플러그인/프록시는 차단합니다. 운영 클러스터나 실제 Windows 10 장비에서 검증했다는 의미는 아닙니다.

## English

This alpha expands the inspection engine while retaining standalone Linux/macOS and Windows 10+ amd64/x86 distributions and the equivalent `kubewiser` / `kubewise` commands. Windows ZIPs ship one EXE and a script registering both names through hardlinks. No Go, Helm or kubectl installation is needed to run the binaries.

- Embed 22 official Kubernetes 1.16–1.37 `.0` OpenAPI bundles with source URLs and hashes; validate local CRDs, unknown fields, types and schema-required fields.
- Separate API deprecation/removal and conditional recommendations; recursively inspect Lists with bounded inputs, source positions, evidence and unchecked areas.
- Collect explicit context/namespace snapshots using bounded GET-only requests, pagination, time/item limits, gap reporting and targeted redaction; never collect Secrets.
- Render local vendored Helm charts and compare desired resources with snapshots; no dependency downloads or apply operations.
- Generate minor upgrade steps/actions and kubelet skew checks; analyze existing Hubble flows, NetworkPolicy isolation intent and EKS/AKS/GKE migration dependencies.
- Expose the same engine through scoped MCP tools; model-controlled paths and cluster scope are not accepted. Collection requires explicit operator opt-in.

**Changes:** report format v2, JSON default output and Go 1.26 minimum for source builds. Runtime analysis is offline with no telemetry. Explicit collection contacts the selected API server. MCP client/model data handling is separate.

**Limits:** `.0` schemas do not establish patch-specific semantics, admission/CEL correctness, actual application/kernel compatibility or complete network reachability. No infrastructure template generation or data migration is performed. Helm values.schema.json and live lookup are not used; exec auth plugins and proxies are blocked. Mock/API and CI validation are not production-cluster or physical Windows 10 validation. See repository documentation for exact coverage.
