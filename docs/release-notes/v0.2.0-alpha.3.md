# v0.2.0-alpha.3

## 한국어

- scan/plan/diff 보고서를 필수·조건부·선택 조치 요약과 현재 상태/권장 상태 비교 중심으로 개선했습니다.
- 문제별 이유, 다음 조치, 검증 방법과 공식 근거를 제공합니다. HTML의 원본 근거·해시는 펼쳐볼 수 있습니다.
- `--lang ko`로 한국어 설명을 선택할 수 있습니다. 기본은 영어이며 원본 근거 문구는 영어로 남을 수 있습니다. JSON/MCP 계약은 유지합니다.
- CPU·메모리 적정값은 실측 필요로 표시하며, 임의의 수치나 자동 패치를 생성하지 않습니다. drift는 무조건 되돌리기 권고가 아닙니다.
- README를 빠른 시작·실제 보고서 미리보기·명령어 색인·펼쳐보는 터미널 예시로 재구성했습니다. 영어 기본과 별도 한국어판을 유지합니다.

보고서 표현을 개선한 알파 릴리스입니다. 실제 앱/커널 호환성, 패치별 의미 검증, 자동 인프라 생성 등 기존 검사 한계는 그대로 적용됩니다. Linux/macOS와 Windows 64/32비트, 두 명령 이름을 유지합니다.

## English

- Redesign scan/plan/diff reviews around required/conditional/optional counts and current-versus-recommended comparisons.
- Show reasons, next actions, verification and references; keep original evidence and hashes in expandable HTML details.
- Add `--lang en|ko` for readable review explanations. English is the default; original evidence may remain English. JSON and MCP contracts are unchanged.
- Require measurements for numeric CPU/memory sizing; do not invent resource values or generate automatic patches. Drift is not a blind-revert recommendation.
- Reorganize the English/Korean READMEs around quick start, real report previews, a command index and expandable terminal examples, with documented primary references.

This alpha improves presentation without extending compatibility guarantees or applying changes. Existing inspection limits and Linux/macOS/Windows amd64/x86 distributions remain.
