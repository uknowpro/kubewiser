# kubewiser v0.1.0-alpha.3

[한국어](#한국어) | [English](#english)

## 한국어

### 추가 기능

- `kubewiser`와 `kubewise` 두 명령 지원. 공통 CLI를 사용하며 옵션, 검사 결과, 종료 코드, MCP 동작이 같습니다. 버전 출력의 제품명은 둘 다 kubewiser입니다.
- 모든 배포 파일에 두 실행 파일 포함. Windows는 `kubewiser.exe`와 `kubewise.exe`이며 셸 별칭이나 Go 설치가 필요 없습니다.
- **Windows 10 32비트 x86** ZIP 추가: `kubewiser_v0.1.0-alpha.3_windows_386.zip`.
- Windows 64비트는 `windows_amd64.zip`을 사용하세요. Linux·macOS amd64/arm64도 계속 제공합니다. 배포 파일 6개 모두 SHA-256 체크섬 제공.

### 사용

압축을 풀고 PowerShell에서 실행합니다. 다운로드한 ZIP의 SHA-256을 `checksums.txt`와 비교하려면 `Get-FileHash 파일명 -Algorithm SHA256`을 사용하세요.

```powershell
.\kubewiser.exe --version
.\kubewise.exe --version
.\kubewise.exe scan files --target-version 1.32 --format json "C:\deploy manifests"
.\kubewise.exe mcp --input "C:\deploy manifests"
```

Linux·macOS에서는 두 실행 파일을 PATH에 포함된 폴더에 설치하면 됩니다. Go 소스 설치 경로도 `cmd/kubewiser`와 `cmd/kubewise` 두 개를 제공합니다.

### 검증 및 제약

- Windows amd64와 386 각각 CI에서 테스트·빌드·실행하며, 한글·공백 경로와 두 명령의 JSON 결과 및 종료 코드 일치를 확인합니다.
- CI는 Windows Server 2022이며 32비트 실행은 WOW64를 사용합니다. Windows 10 또는 순수 32비트 OS 실기기 검증은 수행하지 않았습니다.
- Windows는 서명 미적용, macOS는 Developer ID 서명·공증 미적용입니다. Windows ARM64와 Linux/macOS 32비트 배포본은 포함하지 않습니다.
- 초기 알파 검사 범위는 그대로입니다: YAML 문법·중복 키·필수 문자열·일부 제거된 API. 목표 버전 입력은 1.16~1.32이며 전체 호환성을 보증하지 않습니다.
- 전체 스키마·List 내부 검사·Helm 직접 렌더링·클러스터 수집/drift·네트워크/OS/앱 영향·클라우드 이전·자동 수정은 미구현입니다.
- 외부 텔레메트리·자동 리포팅은 없습니다. MCP 결과(경로·해시·검사 정보)의 클라우드 전달 여부는 연결한 클라이언트 설정에 달려 있습니다.

## English

### Additions

- Both `kubewiser` and `kubewise` commands are supported through one shared CLI. Options, inspection results, exit codes and MCP behavior are identical. Both version banners retain the product name kubewiser.
- Every archive contains both executables (`kubewiser.exe` and `kubewise.exe` on Windows). No shell alias or Go installation is required.
- Added a **Windows 10 32-bit x86** ZIP: `kubewiser_v0.1.0-alpha.3_windows_386.zip`.
- Use `windows_amd64.zip` on 64-bit Windows. Linux/macOS amd64/arm64 remain available. Checksums cover all six archives.

### Usage

Extract the archive and run from PowerShell. Compare the ZIP's SHA-256 with `checksums.txt` using `Get-FileHash FILENAME -Algorithm SHA256`.

```powershell
.\kubewiser.exe --version
.\kubewise.exe --version
.\kubewise.exe scan files --target-version 1.32 --format json "C:\deploy manifests"
.\kubewise.exe mcp --input "C:\deploy manifests"
```

On Linux/macOS, install both executables into a directory on PATH. Go source installation supports both `cmd/kubewiser` and `cmd/kubewise`.

### Validation and limitations

- Windows amd64 and 386 CI runs tests, builds and executables, checking Unicode/spaced paths and identical JSON output/exit codes for both commands.
- CI uses Windows Server 2022; 32-bit executables run under WOW64. Windows 10 and native 32-bit OS device validation has not been performed.
- Windows executables are unsigned; macOS binaries are not Developer ID signed or notarized. Windows ARM64 and Linux/macOS 32-bit archives are not included.
- Initial alpha inspection coverage is unchanged: YAML syntax, duplicate keys, required strings and selected removed APIs. Target inputs are 1.16–1.32, not a guarantee of complete compatibility.
- Full schemas, List item inspection, direct Helm rendering, live collection/drift, network/OS/application impact, cloud migration and automatic remediation are not implemented.
- No external telemetry or automatic reporting is added. Forwarding MCP results (paths, hashes, findings) to cloud services depends on the connected client's settings.
