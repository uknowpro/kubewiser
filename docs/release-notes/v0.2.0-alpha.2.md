# v0.2.0-alpha.2

## 한국어

- 검사·차이 비교·계획·수집 요약에 `--format markdown` 및 `--format html` 추가. `versions`도 두 형식을 지원합니다.
- Markdown 표/목록과 독립 실행형 HTML 보고서에 JSON과 같은 근거·미검사 항목을 유지합니다. HTML은 외부 리소스나 스크립트를 로딩하지 않습니다.
- README에 모든 명령의 설명, 실행/저장 예시, 결과 해석 및 종료 코드를 추가했습니다. 실제 생성한 Markdown/HTML 예제도 제공합니다.
- 입력 문자열의 마크업을 이스케이프하며 출력 실패를 오류로 처리합니다. 발견 사항이 있는 보고서의 종료 코드 1을 유지합니다.

Linux/macOS/Windows amd64·x86 배포 범위와 두 명령 이름을 유지합니다. 이 릴리스는 보고서 표현을 확장하며 검사 범위와 기존 한계는 변경하지 않습니다.

## English

- Add `--format markdown` and `--format html` for inspection, drift, plans and collection summaries; `versions` supports both formats too.
- Preserve JSON report evidence and unchecked areas in Markdown tables/lists and standalone HTML. HTML loads no external assets or scripts.
- Document every command with usage, saved-report examples, interpretation and exit codes; include generated Markdown/HTML examples.
- Escape input-controlled markup, report output-write failures and preserve findings exit code 1.

Retains Linux/macOS and Windows amd64/x86 distributions and both command names. This release expands presentation without changing inspection coverage or existing limitations.
