# kubewiser v0.1.0-alpha.4

[한국어](#한국어) | [English](#english)

## 한국어

Windows 배포 ZIP에는 이제 **`kubewiser.exe` 하나만** 포함됩니다. 중복 `kubewise.exe`는 제외했습니다. Windows 32비트(x86)는 `windows_386.zip`, 64비트는 `windows_amd64.zip`을 선택하세요. Go·WSL 설치는 필요 없습니다.

### 두 명령 사용

압축을 푼 폴더의 PowerShell에서:

```powershell
Set-Alias -Name kubewise -Value (Resolve-Path .\kubewiser.exe).Path
.\kubewiser.exe --version
kubewise --version
kubewise scan files --target-version 1.32 --format json "C:\deploy manifests"
```

현재 PowerShell 세션에 적용됩니다. 영구 등록은 PowerShell 프로필(`$PROFILE`)에 실제 설치 경로를 지정해 `Set-Alias -Name kubewise -Value 'C:\Tools\kubewiser\kubewiser.exe'`를 추가하세요. `kubewiser`도 경로 없이 실행하려면 실행 파일 폴더를 PATH에 추가합니다. CMD의 현재 대화형 세션에서는 `doskey kubewise="C:\Tools\kubewiser\kubewiser.exe" $*`를 사용할 수 있습니다. 별칭은 실제 실행 파일이 아니므로 MCP 클라이언트·배치 스크립트에는 `kubewiser.exe`의 절대 경로를 사용하세요.

### 유지 사항 및 검증

- Linux·macOS 배포본은 두 실행 이름을 계속 제공합니다. 소스 설치 경로 `cmd/kubewise`도 유지됩니다.
- Windows amd64/386 CI에서 단일 EXE와 PowerShell 별칭의 JSON 결과·종료 코드 일치를 검증합니다.
- Windows 10이 대상이나 자동 테스트는 Windows Server 2022/WOW64에서 수행합니다. Windows 10 실기기 검증은 미완료입니다. Windows는 미서명, macOS는 Developer ID 서명·공증 미적용입니다.
- 초기 알파 검사 범위(YAML·일부 제거된 API, 목표 입력 1.16~1.32)는 변경되지 않습니다. 전체 스키마·클러스터·마이그레이션 검사는 미구현입니다.
- 외부 텔레메트리·자동 리포팅은 없습니다. MCP 결과의 외부 전달은 클라이언트 설정에 달려 있습니다.
- Assets의 `checksums.txt`와 다운로드한 파일의 SHA-256을 비교하세요 (`Get-FileHash 파일명 -Algorithm SHA256`).

## English

Windows ZIPs now contain **only `kubewiser.exe`**. The duplicate `kubewise.exe` is removed. Choose `windows_386.zip` for 32-bit x86 or `windows_amd64.zip` for 64-bit Windows. No Go or WSL installation is needed.

### Using both names

In PowerShell, from the extracted folder:

```powershell
Set-Alias -Name kubewise -Value (Resolve-Path .\kubewiser.exe).Path
.\kubewiser.exe --version
kubewise --version
kubewise scan files --target-version 1.32 --format json "C:\deploy manifests"
```

This applies to the current PowerShell session. For persistence, add `Set-Alias -Name kubewise -Value 'C:\Tools\kubewiser\kubewiser.exe'` to your PowerShell profile (`$PROFILE`), using the actual installation path. Add the executable directory to PATH for the bare `kubewiser` command. In an interactive CMD session, use `doskey kubewise="C:\Tools\kubewiser\kubewiser.exe" $*`. Aliases are not standalone executables: configure MCP clients and batch scripts with the absolute `kubewiser.exe` path.

### Retained behavior and validation

- Linux/macOS archives retain both executable names. The `cmd/kubewise` source installation path remains available.
- Windows amd64/386 CI verifies matching JSON results and exit codes between the single EXE and its PowerShell alias.
- Targets Windows 10; automated tests use Windows Server 2022/WOW64. Windows 10 device validation is not complete. Windows binaries are unsigned; macOS binaries are not Developer ID signed or notarized.
- Initial alpha inspection scope is unchanged (YAML and selected removed APIs, target inputs 1.16–1.32). Full schema, live-cluster and migration inspection remain unimplemented.
- No external telemetry or automatic reporting. External forwarding of MCP results depends on the client.
- Compare the download SHA-256 with `checksums.txt` in Assets (`Get-FileHash FILENAME -Algorithm SHA256`).
