# v0.2.0-alpha.7

## 한국어

- 로컬 `scan lifecycle`과 MCP `scan_lifecycle`을 추가하고 업그레이드·AKS 계획에도 지원 종료 검사를 통합했습니다.
- ingress-nginx, AAD Pod Identity, AKS 관리형 NGINX/Pod Identity, Azure Linux 2.0, Ubuntu 20.04, kubenet의 7개 지원 범위를 공식 근거와 함께 제공합니다.
- 종료·예정·이번 달 종료·식별 필요를 구분하고 날짜 정밀도, 평가일, 카탈로그 확인일을 기록합니다.
- 관리형 지원은 명시적 프로젝트 인벤토리로 구분합니다. 사설 이미지·레이블은 확정 증거로 간주하지 않습니다.
- HTML에 종료 시점·지원 범위·식별 근거·대체 조치 표를 추가했습니다. API 제거와 유지보수 종료를 구분합니다.
- 런타임 외부 접속·자동 업데이트·클러스터 변경은 추가하지 않았습니다. 일부 카탈로그 검사이며 모든 제품의 지원 상태를 보증하지 않습니다.

## English

- Add offline `scan lifecycle` and MCP `scan_lifecycle`, also integrated into upgrade and AKS plans.
- Cover seven explicit scopes: upstream ingress-nginx and AAD Pod Identity, AKS managed NGINX and Pod Identity, Azure Linux 2.0, Ubuntu 20.04 and kubenet, with official references.
- Distinguish ended, scheduled, ending-this-month and identification-required results; record date precision, evaluation date and catalog review date.
- Use explicit project inventory to distinguish managed support. Mirror paths and labels remain identification hints.
- Add a dedicated HTML table for deadlines, support scope, evidence and replacement actions. Keep API removals separate from lifecycle dates.
- Add no runtime external connections, automatic downloads or cluster mutations. This selected catalog is not a complete software support audit.
