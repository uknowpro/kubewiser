# v0.2.0-alpha.6

## 한국어

- HTML 검사 결과를 카드 대신 연속된 컴팩트 표로 표시합니다. 필수/조건/선택, 리소스, 현재 상태, 권장 상태, 조치를 비교할 수 있습니다.
- 긴 근거·검증 방법·위치·조치 시점은 행 안에서 펼쳐 확인합니다. 원본 JSON과 미검사 항목은 유지합니다.
- 업그레이드 및 AKS 계획에 As-Is/To-Be 버전 변경 표를 추가했습니다. 최초 영향 버전, API 제거·동작 변경, 권장 조치, 입력에서 발견한 리소스 수를 표시합니다.
- 1.21 → 1.36 HTML 예시와 미리보기, 양국어 README 명령 예시를 추가했습니다.
- 버전 비교 표는 내장 API 제거 규칙과 보고된 동작 변경에 한정됩니다. 전체 릴리스 변경 목록이나 실제 AKS 업그레이드 경로를 보증하지 않으며 미발견을 미사용으로 판정하지 않습니다.
- 분석 결과 JSON과 종료 코드는 유지하며, 외부 접속·클러스터 변경 기능을 추가하지 않았습니다.

```sh
kubewiser plan upgrade --source ./deploy --from 1.21 --to 1.36 --format html --lang ko > upgrade-review.html
```
