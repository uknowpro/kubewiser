# v0.2.0-alpha.10

## 한국어

- HTML 매트릭스의 토픽 그룹·리소스·노드풀 셀을 세로 병합하여 중복 표시를 줄였습니다. 항목별 판정은 병합하지 않습니다. Markdown·터미널도 그룹 순서로 표시합니다.
- 구형 alpha.3 카드 미리보기를 최신 영어·한국어 매트릭스 이미지와 실제 HTML 예제로 교체했습니다.

- 업그레이드·AKS 계획에 manifest와 환경의 전체 검토 매트릭스를 추가했습니다. cgroup·커널·런타임·드라이버 입력 부족과 판정 미지원·실행 검증 필요를 구분합니다.
- `--after PATH`로 현재·제안 manifest의 구조적 차이를 비교하고 제안 파일을 목표 스키마로 재검증합니다. 원문 필드 값은 출력하지 않습니다.
- JSON/HTML/Markdown/text, 한·영 README, 합성 예제 및 로드맵을 갱신했습니다.
- 현재 검사와 변경 후 검사는 별도로 유지합니다. 기본값·admission·실행 호환성을 보증하지 않으며 외부 전송·클러스터 접속은 추가하지 않았습니다.

## English

- HTML matrix groups and resources/node pools now use vertical merged cells; per-check verdicts remain separate. Markdown/text use matching topic groups.
- Replaced historical alpha.3 card previews with current English/Korean matrix screenshots and generated HTML examples.

- Upgrade and AKS plans now include a manifest/environment coverage matrix, keeping missing cgroup, kernel, runtime and driver evidence visible and distinguishing unsupported checks from execution validation.
- Optional `--after PATH` compares current/proposed manifest structure and independently validates proposed manifests against the target schema. Raw field values are omitted.
- Added JSON/HTML/Markdown/text output, bilingual README guidance, synthetic examples and an updated roadmap.
- Current and proposed findings remain separate. No defaulting/admission/runtime compatibility guarantee, cluster access or external reporting is added.
