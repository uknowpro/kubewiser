# v0.2.0-alpha.11

## 한국어

- 11개 MCP 도구에 읽기 전용·파괴성·반복 호출·외부 접근 여부를 명시했습니다. `collect_cluster`만 외부 접근 여부를 true로 표시합니다.
- 모든 도구의 실제 MCP 호출, 정상/오류 응답, 도구 목록의 명시적 boolean 속성, 운영자 범위 우회 거부를 검증합니다. 수집은 로컬 TLS 모의 API에서 GET·namespace·민감 필드 제거를 검사합니다.
- **호환성 변경:** MCP 수집은 `--allow-exec-auth`를 거부합니다. 외부 인증 실행이 필요하면 기존 CLI `collect`를 명시적으로 사용하고 저장된 스냅샷을 MCP에 제공하세요. CLI 인증 기능은 유지합니다.
- 한·영 README, 보안 정책, 검증 근거 및 M8ven 재평가 안내를 추가했습니다. 외부 전송·계정 연결·등급 자체 부여는 하지 않습니다. Trusted 등급은 외부 평가자의 결정입니다.

## English

- All 11 MCP tools declare explicit read-only, destructive, idempotent and open-world hints. Only opt-in `collect_cluster` advertises open-world interaction.
- Added named protocol-call coverage, successful/error responses, serialized boolean-hint checks, operator-scope override rejection and loopback TLS collection tests for GET, namespace and redaction boundaries.
- **Compatibility change:** MCP collection rejects `--allow-exec-auth`. Explicit CLI collection still supports approved authentication executables; pass the saved snapshot to MCP when needed.
- Updated bilingual README, security policy, verification evidence and M8ven reassessment guidance. No telemetry, account linking or self-assigned Trusted status; grading remains the external evaluator's decision.
