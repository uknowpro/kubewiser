# v0.2.0-alpha.13

## 한국어

- `scan cgroup`, `plan upgrade`, `plan aks`에서 추가 옵션 없이 `--source` 범위의 Dockerfile/Containerfile을 자동 검사합니다. 폴더는 하위 경로, manifest 파일은 같은 폴더로 검색을 제한합니다.
- 인식 가능한 Java 베이스 태그의 cgroup v2 기준, v1 파일 참조와 JVM 컨테이너 인식 비활성화 옵션을 파일·단계·줄별로 매트릭스와 기존 결과표에 표시합니다.
- 미확인 태그·지원하지 않는 문법·누락·검색 제한을 명시합니다. 빌드·이미지 다운로드·클러스터 조회 없이 동작하며, 태그 기준 충족을 실제 배포 호환성으로 확정하지 않습니다.
- 한영 README·HTML 예제·Windows PowerShell UTF-8 저장 안내를 추가했습니다. 선택적 `--dockerfile`로 자동 검색 범위 밖 파일 또는 Dockerfile 단독 검사도 가능합니다.

## English

- Automatically inspect Dockerfile/Containerfile declarations in the `--source` scope for CLI cgroup, upgrade and AKS reviews. Directory inputs include descendants; manifest-file inputs search only their own directory.
- Add stage/line evidence for selected Java cgroup v2 baselines, v1 file references and disabled JVM container awareness to the grouped matrix and inspection table.
- Keep ambiguous tags, unsupported syntax, missing files and discovery limits visible. No build, image pull or cluster request occurs; meeting a declared baseline is not deployed-image compatibility certification.
- Add bilingual README/HTML examples and Windows PowerShell UTF-8 instructions. Optional `--dockerfile` provides an explicit override or standalone Dockerfile review.
