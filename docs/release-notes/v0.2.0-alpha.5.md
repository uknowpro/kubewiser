# v0.2.0-alpha.5

## 한국어

- 지정된 절대 경로 실행 파일만 허용하는 선택적 exec 인증. 기본 차단, 비대화형·시간/출력 제한, 토큰과 오류 원문 비출력. 이 옵션은 인증 서버 통신을 동반할 수 있습니다.
- AKS 조회 JSON의 클러스터·현재 버전·조회 시각·다음 제공 후보를 대조합니다. 전체 업그레이드 경로 승인은 아닙니다.
- 1.35.9·1.36.5·1.37.1 정확한 패치 스키마를 추가하고, 실제 `description` 필드가 누락되던 번들 축약 오류를 수정했습니다. 모든 공식 원본 해시를 검증했습니다.
- `scan cel` 및 MCP `scan_cel`: 공식 Kubernetes 라이브러리 기반 로컬 CRD CEL·oldSelf 검사와 비용 제한.
- `diff --crd-defaults --crd-conversion`: 로컬 기본값과 strategy None 변환을 선택적으로 반영하며 Webhook 변환은 실행하지 않습니다.
- 공식 근거의 일부 애드온 카탈로그, 노드 런타임·로컬 OCI 플랫폼/digest 근거 검사.
- Service→Pod/targetPort 분석과 포트·프로토콜별 Hubble 관측 연결.
- 요구사항을 반영한 노드풀·canary 템플릿, 목표 스키마·label/quantity·HCL 문법 검증. 실행은 기본 비활성.
- 양국어 문서·로드맵을 현재 구현과 실제 환경 검증 경계에 맞춰 정리했습니다.

실제 AKS 변경, admission webhook, 앱 실행/커널 검증, CNI/클라우드 방화벽 실통신, Terraform provider 적용, 데이터 이전은 수행하지 않습니다. 공급자 근거와 스냅샷의 최신성·진위는 별도 확인해야 합니다.

## English

- Add opt-in exec authentication for an explicitly approved absolute executable, with noninteractive execution, bounded time/output and no credential/error-output logging. This option may contact identity services.
- Cross-check local AKS upgrade-profile exports against cluster, current version, capture age and next offered candidates; never certify an entire future path.
- Add pinned 1.35.9/1.36.5/1.37.1 schemas. Fix schema reduction dropping legitimate properties named `description`; verify all official source hashes.
- Add `scan cel` / MCP `scan_cel` using the pinned Kubernetes CEL implementation, explicit old objects and bounded evaluation cost.
- Add opt-in local CRD defaulting and strategy None conversion for drift; never invoke conversion webhooks.
- Add selected vendor-sourced add-on rules, Node runtime inventory and local OCI platform/digest checks.
- Follow Service selectors/targetPort to supplied Pods and attach protocol/port-matched Hubble evidence.
- Generate parameterized node-pool/canary review templates with schema, label/quantity and HCL syntax checks; execution remains disabled by default.
- Reconcile bilingual guides and roadmap with implemented behavior and environmental validation boundaries.

No live AKS change, admission webhook execution, workload/kernel execution, dataplane/firewall probing, Terraform provider application or data movement is performed. Local exported evidence is not independently authenticated.
