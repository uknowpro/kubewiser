# v0.2.0-alpha.4

## 한국어

- `plan aks`: 가변 버전, 기존 AKS 업그레이드, 아키텍처 변경 요구사항과 로컬 애드온 호환성 근거를 함께 검토합니다. 실제 업그레이드 경로·복구 리허설·PDB/여유 용량 확인을 필수 조치로 표시합니다.
- `generate`: 새 디렉터리에 검토용 Terraform 노드풀, 기본 비활성 Helm 차트, replica 0 manifest, 검수 체크리스트를 생성합니다. 배포와 원본 워크로드 자동 변환은 하지 않습니다.
- `scan path`: 두 Pod의 ingress/egress 정책, selector, port, IPBlock을 정적으로 평가합니다. 불충분한 근거는 unknown이며 실통신 보증이 아닙니다.
- CRD map/set 목록의 순서 차이를 처리하고 managedFields 관리자 근거를 추가합니다. 소유권 근거만으로 수정·삭제를 권고하지 않습니다.
- API 수정 시점을 첫 영향 버전에 맞추고 dockershim/토큰/PSP 변경 및 노드 OS·런타임 의존성 검토를 추가합니다.
- Jobs/ReplicaSets/HPA 수집과 알려진 구버전의 beta API 선택을 추가합니다.
- `mcp --profile`에 운영자가 고정한 `plan_aks` 도구를 제공합니다. 생성/배포 도구는 노출하지 않습니다.

Linux 우선 검증 릴리스입니다. 실제 AKS 실행, 공급자 호환성 근거의 독립 검증, Terraform provider 실행, CEL/admission·API 변환은 포함하지 않습니다. 모든 분석은 로컬이며 명시적인 collect만 선택한 API 서버와 통신합니다.

## English

- Add `plan aks` for variable upgrade ranges, in-place AKS architecture requirements and operator-supplied add-on evidence. Require actual offered-route, recovery, disruption and capacity reviews.
- Add `generate` for local review-only Terraform user-pool, disabled Helm canary, zero-replica manifest and acceptance checklist in a new directory. No deployment or production workload conversion.
- Add `scan path` for two-Pod ingress/egress policy intent, selectors, ports and IPBlocks with explicit unknown results; this is not reachability testing.
- Compare CRD map/set lists using supplied schemas and include recorded field-manager hints without overwrite/deletion recommendations.
- Place API deadlines at the first affected version; add dockershim/token/PSP milestones and node runtime/OS dependency reviews.
- Collect Jobs/ReplicaSets/HPAs and select known older served beta APIs.
- Expose `plan_aks` via an operator-fixed MCP profile; no generation or deployment tool.

Linux-first validation. Live AKS execution, independent vendor-matrix verification, Terraform provider execution, CEL/admission and API conversion remain outside coverage. Offline by default; only explicit collection contacts the selected API server.
