# v0.2.0-alpha.12

## 한국어

- 저장된 Node·Pod·템플릿을 이용해 관측 배치와 배치 후보를 구분하고 노드풀 cgroup 전환 영향에 연결합니다. 선택적 `node_selector`로 풀 식별 근거를 지정할 수 있습니다.
- PDB 선택자·예산·제공 상태, 단일 복제본, 로컬 볼륨과 대체 노드 제약을 오프라인으로 검토합니다. 실제 drain·eviction·클러스터 조회는 하지 않습니다.
- `--after`에서 동일 목표 버전의 문제를 해결됨·남아 있음·새로 발생·비교 불가로 추적합니다. 일부 cgroup 의존성과 단일 복제본/로컬 볼륨 위험을 포함합니다. 삭제·이름 변경·불완전 스냅샷을 해결로 오판하지 않습니다.
- 그룹 매트릭스·기존 결과표·한영 README·합성 예제를 갱신했습니다. 전체 스케줄러, 무중단 또는 앱 실행 호환성을 보증하지 않습니다.

## English

- Link observed Pod bindings and hard-constraint workload candidates to node pools and supplied cgroup transitions. Optional pool `node_selector` provides explicit label matching.
- Review PDB selectors/budgets/supplied status, single replicas, local volumes and alternate-node constraints offline. No drain, eviction or live cluster lookup is performed.
- `--after` tracks resolved, remaining, introduced and incomparable findings against the same target version, including selected static cgroup and replica/volume risks. Missing/renamed resources and incomplete snapshots are not marked resolved.
- Updated grouped matrices, existing result tables, bilingual README and synthetic examples. This is not a full scheduler, zero-downtime or application runtime certification.
