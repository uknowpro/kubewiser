# kubewiser v0.1.0-alpha.2

## 한국어

### 변경 사항

- **Windows 10 이상 x64(Intel/AMD)용 ZIP 배포본** 추가: `kubewiser_v0.1.0-alpha.2_windows_amd64.zip`.
- Go·WSL 설치 없이 PowerShell/CMD에서 `kubewiser.exe` 실행.
- Windows CI: 검사 엔진·MCP 테스트, 정적 검사, 실행 파일 빌드, 한글·공백 경로와 JSON 결과 검증.
- 기존 Linux·macOS amd64/arm64 배포 유지. 전체 배포 파일의 SHA-256 체크섬 제공.
- 한국어·영어 릴리스 노트를 저장소에서 관리하고 릴리스 자동화에 반영.

### Windows 설치와 실행

Assets에서 Windows ZIP과 `checksums.txt`를 다운로드합니다. 아래 해시를 체크섬 파일의 해당 항목과 비교한 후 압축을 해제하세요.

```powershell
Get-FileHash .\kubewiser_v0.1.0-alpha.2_windows_amd64.zip -Algorithm SHA256
Expand-Archive .\kubewiser_v0.1.0-alpha.2_windows_amd64.zip -DestinationPath .\kubewiser
cd .\kubewiser
.\kubewiser.exe --version
.\kubewiser.exe scan files --target-version 1.32 --format json "C:\deploy manifests"
.\kubewiser.exe mcp --input "C:\deploy manifests"
```

더블클릭하는 GUI가 아닌 콘솔 프로그램입니다. CLI 옵션은 입력 경로 앞에 지정합니다. 종료 코드: 0=수행한 검사에서 발견 사항 없음, 1=발견 사항 있음, 2=인자/실행 오류.

### 지원 범위 및 검증 한계

- Windows 10 64비트가 대상이며 32비트·ARM64 Windows 배포본은 포함하지 않습니다.
- [Go 공식 최소 요구사항](https://go.dev/wiki/MinimumRequirements)에 따라 Windows 10을 대상으로 합니다. 자동 실행 검증은 **Windows Server 2022**에서 수행하며, Windows 10 실기기 검증을 완료했다는 의미는 아닙니다.
- Windows 실행 파일은 Authenticode 서명 미적용이며 SmartScreen 경고가 표시될 수 있습니다. macOS는 Developer ID 서명·공증 미적용입니다.
- 검사 기능은 초기 알파 범위입니다: YAML 문법·중복 키·필수 문자열·일부 제거된 API 검사. 목표 버전 입력은 1.16~1.32이며 전체 호환성을 보증하지 않습니다.
- 전체 스키마, List 내부 항목, Helm 직접 렌더링, 클러스터 수집·drift, 네트워크·OS·앱 영향, 클라우드 이전·자동 수정은 미구현입니다. Helm은 별도 렌더링이 필요합니다.
- 외부 텔레메트리·자동 리포팅은 없습니다. MCP는 연결한 클라이언트에 파일 경로·해시·검사 정보를 반환하므로 클라우드 전송 여부는 클라이언트 설정에 달려 있습니다.

## English

### Changes

- Added a **Windows 10+ x64 (Intel/AMD) ZIP**: `kubewiser_v0.1.0-alpha.2_windows_amd64.zip`.
- Run `kubewiser.exe` from PowerShell or CMD without installing Go or WSL.
- Added Windows CI for scanner/MCP tests, static checks, executable builds, Unicode/spaced paths, and JSON output.
- Retained Linux/macOS amd64/arm64 archives. SHA-256 checksums cover every distribution archive.
- Bilingual release notes are now maintained in the repository and used by release automation.

### Windows installation and usage

Download the Windows ZIP and `checksums.txt` from Assets. Compare the hash with its entry in the checksum file before extraction.

```powershell
Get-FileHash .\kubewiser_v0.1.0-alpha.2_windows_amd64.zip -Algorithm SHA256
Expand-Archive .\kubewiser_v0.1.0-alpha.2_windows_amd64.zip -DestinationPath .\kubewiser
cd .\kubewiser
.\kubewiser.exe --version
.\kubewiser.exe scan files --target-version 1.32 --format json "C:\deploy manifests"
.\kubewiser.exe mcp --input "C:\deploy manifests"
```

This is a console application, not a double-click GUI. Place options before the input path. Exit codes: 0 = no findings in performed checks; 1 = findings; 2 = argument/operational failure.

### Support and validation limits

- Targets Windows 10 64-bit; Windows 32-bit and ARM64 binaries are not included.
- Windows 10 is targeted according to the [Go minimum requirements](https://go.dev/wiki/MinimumRequirements). Automated runtime checks run on **Windows Server 2022**, not a Windows 10 desktop. Windows 10 device validation has not been performed.
- Windows binaries are not Authenticode-signed and may trigger SmartScreen. macOS binaries are not Developer ID signed or notarized.
- Inspection remains initial-alpha functionality: YAML syntax, duplicate keys, required strings, and selected removed APIs. Accepted target versions are 1.16–1.32; this is not complete compatibility coverage.
- Full schemas, List item inspection, direct Helm rendering, live collection/drift, network/OS/application impact, cloud migration, and automatic remediation are not implemented. Render Helm separately.
- No external telemetry or automatic reporting is added. MCP returns paths, hashes and inspection data to its client; cloud forwarding depends on the client's configuration.
