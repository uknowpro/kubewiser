검사하지 못한 항목

발견 사항이 없어도 아래 검증 한계는 남아 있습니다.

  • Cgroup results compare supplied evidence/declarations, not live nodes. OS or Kubernetes versions alone never establish the active cgroup mode.
  • Equal modes or minimum prerequisites do not certify application compatibility. Test memory limits/OOM, CPU throttling, agents and application runtime versions on target nodes.
  • Workload hints are not mapped to individual pools; scheduling and node-pool membership require validation. Redacted snapshots can hide commands, environment values and host paths.
